# Game Night — releases

Download builds of **Game Night**, a table of party games for friends: İsim Şehir, Hidden Links and Odd One Out. English and Turkish.

## Install (Windows)

1. Open the [latest release](../../releases/latest).
2. Download `GameNight-windows.zip` and unzip it into any folder you can write to (for example `Documents\Game Night`).
3. Run `GameNight.exe`.

## Updates

You only download once. When a newer version is published here, the game shows **"There is a newer version"** on launch. Press **Update now**: it downloads the new build, restarts, and you are on the latest version.

This repository holds releases only. The source code is private.
